# Handoff feat-ui-html-automation (claude)

**Đã làm:** dựng lại `/app/automation` và `/app/spam-rules` từ HTML Stitch; kit `Inset` mới; CSS tách `automation.css`/`spam-rules.css`; đo bbox `e2e/support/measure-automation.mjs`.
**Đã đọc, rút ra:** form tự gửi dùng tên trường `mode:<kênh>:<đối tượng>:<nhãn>` (giữ nguyên); `.visually-hidden` trong bảng cần `td { position: relative }` kẻo tràn ngang mobile; Enter trong form spam kích nút submit đầu tiên (đặt Xem trước đứng đầu).
**Còn lại:** Dừng khẩn cấp, thẻ số liệu, kiểu trả lời, danh sách/nhật ký quy tắc (xem Q-UIHA1). Biểu tượng dùng lucide, không nạp Material Symbols từ máy chủ ngoài.
